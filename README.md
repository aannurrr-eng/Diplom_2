# Диплом_2
Тестирование API сервиса  Stellar Burgers.

Технологии, используемые в проекте:

- Java 11
- JUnit 4.13.1
- Rest-assured 5.5.6
- Allure
- Maven 3.6.3

Команда для запуска тестов:

`mvn clean test`
